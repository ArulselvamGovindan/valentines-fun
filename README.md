# Valentine Fun (Ionic + Angular)

A playful Valentine page with a teasing button, animated reveal, and sections for GIFs, photos, notes, and YouTube videos.

## Run locally

1. Install dependencies:
   - `npm install`
2. Start the dev server:
   - `npm start`

## Replace placeholders

- Images/GIFs: replace files in `src/assets/placeholders/` with your real media.
- Videos: update `videoIds` in `src/app/home/home.page.ts` with real YouTube IDs.
- Text: update the hero message and love notes in `src/app/home/home.page.html` and `src/app/home/home.page.ts`.
